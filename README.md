# CustomBatteryV2

Custom floating battery indicator for Android with a personalized photo.

## Features

- Floating battery indicator
- Real-time battery percentage
- Charging animation
- Personalized photo
- Draggable overlay
- Android app project

## Project

The Android project files are available in the ZIP archive:

`CustomBatteryV2_AndroidProject.zip`

## Installation

1. Download the ZIP file.
2. Extract it.
3. Open the project in Android Studio.
4. Build and install the application.
